EXAMPLE LESSON. This shows the shape of a lesson. Delete it once there are 5 real lessons.

"I found nothing" needs proof that the search ran on the right place, and how much it looked through.

**Why:** on 2026-02-17, a search of the inbox for an investor's reply came back empty, and the user was told
the investor never answered. The search had run on the wrong account. The reply had been sitting there for
a week.
**How to apply:** when a search finds nothing, say where it searched and how many items it covered, and
try one search you know should find something, to prove the search works.
