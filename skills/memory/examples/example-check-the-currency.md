---
title: "EXAMPLE: Check the currency before comparing prices"
when: Any time two prices from different sources are compared or added up
---
EXAMPLE LESSON. This shows the shape of a lesson. Delete it once there are 5 real lessons.

Before comparing or adding prices, check that they're in the same currency and include the same things
(tax, shipping).

**Why:** on 2026-02-03, two supplier quotes were compared as if both were in dollars. One was in euros and
excluded shipping, so the "cheaper" supplier was about 15% more expensive. The user nearly signed it.
**How to apply:** write the currency and what's included next to every price you copy. Convert before
comparing, and say which rate and date you used.
